# 🦂 Scorpion Cursor

An interactive **Scorpion Cursor Animation** built using pure **HTML, CSS, and JavaScript** with the **HTML5 Canvas API**.

The project creates a minimal black-and-white scorpion-like animation that follows the user's mouse movement. The scorpion is made from multiple animated body segments, articulated legs, pincers, antennae, a segmented tail, and floating particles.

## 🌐 Live Demo

https://scorpian-cursor.vercel.app/

## ✨ Features

- 🦂 Interactive scorpion cursor animation
- 🖱️ Smooth mouse-following movement
- 📱 Touch movement support
- 🦵 12 articulated animated legs
- 🦂 Segmented animated tail
- ⚔️ Animated pincers and antennae
- ✨ Floating particle effects
- 🎯 Dynamic cursor point
- 📐 Responsive canvas
- ⚡ Lightweight and fast
- 🚫 No external libraries or frameworks
- 🌑 Minimal dark visual design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- HTML5 Canvas API
